# m-app-resource

## 项目简介

`m-app-resource` 是一个用于归档和发布多个独立 HTML 页面的仓库。本项目不绑定任何特定域名或网站，仅作为静态资源的集中存储与版本管理平台。

仓库中的 HTML 页面彼此独立，适用于多种使用场景，包括但不限于演示、测试、文档展示或轻量级工具页面。每个页面均可直接通过浏览器打开运行，无需额外后端支持。

## 目录结构

```
m-app-resource/
├── pages/          # 存放所有独立 HTML 页面
│   ├── page-a.html
│   ├── page-b.html
│   └── ...
├── assets/         # 页面引用的公共资源（CSS、JS、图片等）
├── docs/           # 项目相关文档或说明
└── README.md       # 本文件
```

- `pages/`：核心目录，每个 HTML 文件为一个独立页面。
- `assets/`：存放页面公用的样式、脚本或媒体文件，便于复用。
- `docs/`：可选，用于存放额外文档或使用指南。

## 页面归档说明

1. **独立性**：每个 HTML 页面应自包含其所需资源，或仅引用 `assets/` 目录下的公共文件。避免页面间的交叉依赖。
2. **命名规范**：页面文件名使用小写字母和连字符，例如 `example-page.html`。
3. **兼容性**：建议页面兼容主流现代浏览器（Chrome、Firefox、Edge 等）。如需特定环境，请在页面注释中注明。
4. **版本管理**：通过 Git 提交记录追踪页面变更。建议为重要更新添加有意义的提交消息。

## 维护说明

- **新增页面**：将 HTML 文件放入 `pages/` 目录，并确保所有资源引用正确。
- **更新页面**：直接修改对应 HTML 文件，提交前请验证页面功能正常。
- **清理旧版**：如需移除页面，请删除文件并提交。建议在提交消息中说明移除原因。
- **贡献指南**：欢迎提交 Pull Request。请保持代码整洁，避免引入外部敏感内容或恶意脚本。
